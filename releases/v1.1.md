# v1.1 · 越思考越强

从"思考协议"进化为"自进化系统"：元体系闭环、无感知补丁、辩证取舍、旁路沉淀、产出协议。

## 安装

下载本 release 附件 `essence-thinking.skill`（SHA-256: `2d4611b203e8a48bd32c709249d994ee24db273808b778f7491c20b51c8c6649`，34.8 KB），在 Kimi Work 中安装，或将 `essence-thinking/` 目录放入 skills 目录。

## v1.0 → v1.1 变更

**新增机制**
- **元体系**（references/meta.md）：事实→元原则→元逻辑→方法→产物五层结构，层间双向闭环，修订稳定性梯度（越深层门槛越高）
- **无感知进化**（references/self-evolve.md）：思维结论经补丁提案队列（`.essence/patches/`）延迟合并回本体——快速记录、批量应用、合并必有记录；低风险类自动应用，协议类人工确认
- **旁路沉淀**（references/side-channel.md）：大任务中分支思路 ≤20 秒一句话捕获进 inbox，主线停顿点批量消费——跃迁发生且无感知
- **辩证取舍**（元原则）：Consolidate 段改为"先正评→再攻击→后取舍"，禁止上来就否定
- **验证分级**（元逻辑）：验证强度 ∝ 推翻代价 × 新颖度——继承式思路做论证链追溯+抽样复核，全新结论全量红队
- **产出协议**（references/report.md）：思维报告三级模板，"风险与待推敲"强制节——报告是让人类加入闭环的接口
- **软约束插件化**（references/plugins.md）：本体只留协议骨架，判定标准一句话——"改它不用动 SKILL.md 的就是插件"
- **路由收割**：被委托 skill 的方法论提炼进模式库，越用越强

**工具**
- `et_log.py` 新增 `--patch`：补丁提案自动落盘队列

**质量红线升级**
- 置顶两条：事实是一切（无事实锚点不许沉淀）、辩证取舍（禁止上来否定）
